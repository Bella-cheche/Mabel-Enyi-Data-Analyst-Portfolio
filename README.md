# Mabel Enyi — Data Analyst Portfolio

Personal portfolio website built with HTML, CSS and JavaScript.

## Sections
Home · About · Skills · Projects · Analytical Approach · Contact

## Final setup
Replace the temporary GitHub, email, Resume and project links in `index.html` with the final URLs.

## Publish with GitHub Pages
Create a repository named `<your-github-username>.github.io`, upload these three website files to the root, then enable GitHub Pages in repository Settings → Pages.

A custom domain can be connected later.
